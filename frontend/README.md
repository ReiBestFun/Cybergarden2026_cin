# CyberFlow — Frontend MVP

Светлый визуальный редактор сценариев безопасности для Cyber Garden 2026.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite (обычно http://localhost:5173).

## Возможности

- Четыре страницы: сценарии, редактор, результаты, история.
- Drag-and-drop нод из библиотеки, соединение и редактирование настроек.
- Сохранение графа в localStorage и экспорт JSON.
- Демонстрационная анимация запуска, без выполнения сканеров.
- Заглушка AI-чата. Настоящая LLM пока не подключена.
- Демо-таблица результатов. Она **не** отражает реальные находки учебного репозитория.
