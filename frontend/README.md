# CyberFlow — Frontend

Визуальный редактор сценариев проверки безопасности для Cyber Garden 2026. Работает поверх API из [backend/](../backend/README.md).

## Запуск

Требуется Node.js 20+. Сначала поднимите бэкенд и воркер по инструкции в backend/README.md.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Vite проксирует `/api` на http://127.0.0.1:8000. Другой адрес API задаётся переменной `VITE_API_PROXY` для dev-сервера или `VITE_API_BASE_URL` для сборки.

## Возможности

- Каталог нод, их порты и формы настроек загружаются из `GET /api/check-types`. Если API недоступен, редактор показывает офлайн-каталог и предупреждение.
- Соединения проверяются по типам портов, на циклы и на повторное подключение к входу, который принимает одно соединение.
- Сценарий сохраняется на сервере. До сохранения черновик хранится в памяти редактора.
- Запуск выполняется воркером бэкенда. Статусы нод обновляются по ходу выполнения, а при выборе ноды видны её ошибка и данные выхода.
- В ручном сценарии или расписании добавьте из «Источников» ноду «Локальный ZIP», выберите файл в её настройках и соедините с триггером и анализаторами. В существующей ноде «Репозиторий» кнопка «Использовать локальный ZIP» сохраняет связи. Сценарий запоминает конкретную версию архива.
- В сценарии GitHub Actions раскройте «Настроить автоматический запуск», выберите runner для push и скачайте `security.yml`. CI проверяет SHA из репозитория.
- Результаты, история запусков и список сценариев берутся из API. Отчёт можно скачать в JSON и Markdown.
- «Создать по описанию» строит редактируемый сценарий с помощью LLM. Нода «AI-отчёт» объясняет находки в результатах запуска. [Настройка модели](../backend/MCP.md)
